Floating Markdown Note

Markdownで書いて、プレビューできる付箋をデスクトップ上に1枚浮かべます。

Chrome / Edge などの Document Picture-in-Picture 対応ブラウザ向け。

準備完了。ボタンを押して付箋を開いてください。

使い方

  • 「付箋を開く」でPiPウィンドウを開きます。PiP自体が1枚の付箋です。
  • 「編集」と「プレビュー」を切り替えてMarkdownを編集します。
  • Markdownの区切り線（---）などで内容を整理できます。
  • marked.jsをCDNから読み込み、HTMLタグやiframeもプレビューに反映します。外部ライブラリの読み込みにインターネット接続が必要です。
  • ローカルファイルのフルパス貼り付けは、OS・ブラウザがクリップボードに渡す内容に依存します。ファイルマネージャーからファイルをコピーしても、ブラウザにはファイル名やファイルデータしか渡らず、パスを取得できない場合があります。
